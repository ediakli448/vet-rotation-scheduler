# שיבוץ בלוקים קליניים – שנה ד׳ ברפואה וטרינרית

מערכת לשיבוץ וניהול בלוקים קליניים לסטודנטים בשנה ד׳, בית הספר לרפואה וטרינרית ע״ש קורט, האוניברסיטה העברית.

## הקבצים

| קובץ | מה זה |
|---|---|
| `coordinator.html` | אפליקציית הרכזים: שיבוץ אוטומטי, עריכה ידנית עם החרגות, תורנויות, הצגות מקרה, תיבת בקשות, ייבוא מהשאלון ומטופס השיבוצים, ופרסום מוצפן לפורטל |
| `student-portal.html` | פורטל הסטודנטים: טופס העדפות, צפייה בלו״ז האישי (מוצפן בקוד אישי) ובקשות שינוי במהלך השנה |

שני הקבצים הם עמודי HTML עצמאיים (HTML, CSS ו-JavaScript בקובץ אחד), שנבנו כ-Artifacts ב-claude.ai.

## הרצה

אפשר לפתוח כל קובץ ישירות בדפדפן. שימו לב:

- **שמירת נתונים:** באפליקציית הרכזים הנתונים נשמרים במסד הנתונים של ה-Artifact (`window.claude` db). מחוץ ל-claude.ai היכולת הזו לא זמינה, ולכן עובדים דרך **ייצוא / ייבוא JSON**.
- **סנכרון ל-Google Sheets** עובר דרך Zapier בתוך claude.ai, ולא יפעל מחוץ לו. מזהה הגיליון מוגדר ב-`GS_ID` בקובץ `coordinator.html`.

## פרטיות

הריפו מכיל **קוד בלבד**, בלי נתוני סטודנטים. אין להעלות לכאן:

- קובצי ייצוא JSON מהאפליקציה
- את טופס השיבוצים או את קובץ התשובות לשאלון (xlsx / csv)
- קודים אישיים של סטודנטים או חבילות פרסום

קבצים כאלה חסומים ב-`.gitignore`.
